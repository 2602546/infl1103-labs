1. how well does the current design support adding a new product type?

it works, but it doesn't do it well. when adding a new product type, one would need to add a new elif() branch into add_product() inside inventory_manager.py.

2. which parts of the existing system needs to change?

create_product(): a new elif branch for "subscription" when loading from JSON.
add_product(): the type menu and the input check had to accept a third option.
add_product(): a new branch to prompt for the duration and build the object.

3. how could the design be enhanced to remove these changes?

from_dict() should be modified to include the product types. right now, we are using a if/elif chain for the different product types, however, if the inventory has many different product types, it would be a very lengthy chain.
